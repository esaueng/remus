Tier: core. The existing `project_curve_onto_face` / `projectCurveOntoFace`
now admit one complete open positive-weight, clamped single-span rational
Bezier, degree 1–8 / CP 2–9, on a strictly convex hole-free native-plane face
with 3–32 complete Line boundary edges. The authoritative Loop/Coedge use
list is capped and validated against its compatibility wire before geometry
certification; a stale enlarged shadow cannot authorize an outside image. The degree, full evaluator-safe native
chart and weights are retained. Original-ray/plane interval coefficients
certify forward travel, whole-control-hull containment and emitted-coordinate
error before any topology publication; no fitting or clipping is used. The
optional 2D output retains the same chart/weights and additionally requires
raw weights at least 4 machine epsilon for the existing evaluator. Its
bounded positive-basis evaluation/conditioning and actual frame-reconstruction
roundoff must also fit the same face-only band; far in-plane frames refuse
rather than silently magnifying evaluation error. Source
endpoint tolerance, target/frame/image bounds and resource budgets are
separate. Unsafe chart arithmetic, partial coverage, holes, nonconvex/curved
boundaries, tangencies, multispan sources and unresolved ray images refuse.

The output adds one free edge, two vertices and a scoped journal barrier;
source/target bodies and earlier history are preserved. Refused direct and
both batch calls retain any checkpoint-shared topology owner, with the
unshared fast path and existing transaction policies preserved. The existing
entry points have no operation-context/cancellation-token argument, so this
slice makes no cancellation claim. CP 9/face 32 and caller `maxControlPoints`
bound this newly admitted family; existing projection routes retain theirs.

Independent weighted-Bernstein and ray/plane oracles cover degrees 1 / 2 / 3 / 8,
three scales, rigid placement, shifted/negative charts, oriented polygon uses,
material boundary/inside/outside probes, resource edges, between-sample
excursions, raw-direction cancellation/normalization, tiny retained weights,
subnormal charts, and whole-call ownership/history refusal boundaries.
`qualify_project_curve.rs` retains all existing accepted-cell oracles; the
unsupported NURBS remainder is now explicitly multispan. The existing
`project-curve-packaged.mjs` helper drives the new direct/legacy/V2 witnesses
through both canonical fresh and installed-tarball consumers. Actual native
counts, immutable-source package provenance and restored byte/mode receipts
are recorded with the PR qualification.
