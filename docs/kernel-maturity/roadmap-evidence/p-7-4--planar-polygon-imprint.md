Tier: core. `imprint_planar_polygon` / `imprintPlanarPolygon` add a live
construction partition for one native planar, hole-free, convex all-Line
solid face (target cap32) and a strictly interior convex world-point ring
(3–16 vertices). The inner patch and annular surround share opposite uses
of the exact ring. Outward interval whole-polygon halfspace proofs reject
stars and unresolved clearance; existing tolerance, segment/pair budgets,
strict validators and cancellation remain intact. A single transaction
opens the journal before private ring allocation, clones only the owning
shell, preserves cavities and attributes, and records total F/E/V
Modified/Generated/Preserved construction history. Six native tests cover
three scales, rigid3D placements, reversed rings and cavity face uses,
areas16/64, volume320 (cavity312), material probes, raw and independently
welded directed mesh closure/volume, every event, 3/16 and32/33 admission
bounds, star/nonfinite/degenerate/boundary/resource/cancel refusals and
post-allocation rollback. Public contract tests cover direct and both
batch routes, typed refusals, face names, prior-reference continuity,
checkpoint undo, handle/op nonreuse, and exact checkpoint memory-sharing
refusals while unshared late-failure slots remain retired. The permanent39-cell public
witness is wired into fresh and installed-tarball canonical consumers;
package execution results accompany the PR. The check-crate chi3 Euler
warning for the annular face remains visible, with zero validation errors.
