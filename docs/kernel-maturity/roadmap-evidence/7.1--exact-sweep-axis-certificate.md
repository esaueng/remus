Exact-sweep axis certificate (2026-11-18, PR #1852, merge
`c7e2dc168d232918652e1084300bd7a12216f4bc`): for each arc segment,
`sweep_exact` now proves rotational transversality over every profile edge's
whole domain (`nurbs::reuse::certify_rotational_crossing`: interval bounds on
the control hull, refined per span in homogeneous Bernstein form) instead of
at samples, so a quadratic profile edge that crosses an arc's axis between
samples is refused atomically while a nearby profile that clears the axis
still sweeps
(`exact_sweep/tests.rs::an_axis_crossing_between_profile_samples_is_refused_atomically`).
