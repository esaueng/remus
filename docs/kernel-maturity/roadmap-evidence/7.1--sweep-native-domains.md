Tier: core (this corrects existing sweep entry points that consume live profile
and path handles, allocate session topology, and participate in checkpoint
transactions). No new module or twist/loft control is introduced.

The parameter contract distinguishes normalized progress `q` in `[0,1]` from
the path's native parameter. Scale-law closures and sampled scale-law pairs
continue to use `q`. Geometry, endpoint/closure probes and orientation samples
must cover the complete native domain. Clamped single-span curves may use an
exact internal `[0,1]` knot chart with unchanged control points and weights;
this is an affine reparameterization, without refitting or a new approximation.
The public path remains unchanged. General paths retain their native knots;
unresolvable requested sample stations require a typed refusal, rather than
duplicate rings or silently clamped path samples. Existing unit-domain and
working multispan/miter/round behavior must remain compatible.

An auxiliary guide must have the same native domain as the main path before
any internal chart conversion. Mismatched domains are an explicit unsupported
configuration; this slice does not invent a guide correspondence policy.

Qualification targets the existing affinely parameterized +Z line path and XY
straight-edge polygon/hollow profile family, with normalized linear and aligned
piecewise-linear laws. The acceptance matrix includes negative/shifted/nonunit,
coarse large-anchor and huge finite domains, three model scales and translated
placement; independent physical endpoint/section, frustum-volume, material,
strict-validation and raw/welded-mesh oracles; refusal rollback; and native,
direct, both batch and fresh/installed package consumers. General curved paths,
nonlinear continuous scale-law error bounds and arbitrary initial roll remain
separate qualification boundaries. Validation evidence is recorded when the
implementation and its tests are complete.


The existing sweep entry points do not receive an `OperationContext` or a
cancellation token. This slice adds neither a cancellation API nor a
cancellation claim. It retains the JS parser's 10,000-segment bound and adds
checked native sample-count arithmetic and finite/ordered parameter guards.
A refused checkpoint-backed sweep retains the exact shared document owner;
callbacks change topology only and publish a result handle only on success.
Unshared calls keep their existing private-slot high-water/retirement behavior.
General multispan charts are retained, with finite and strictly ordered actual
sample stations checked; this is not a continuous sampling-error certificate
for general or coarsely encoded multispan paths.


The native matrix changes only endpoint knot labels for the same degree-one,
unit-weight path: `[0,1]`, `[10,20]`, `[-20,-10]`, `[-2,3]`, `[0,2]`, `[-1,1]`,
`[1e16,1e16+16]`, `[1e16,1e16+64]` and `[0,1e308]`. The coarse charts request
16/64 sections, exceeding the number of representable native interior sample
coordinates. Independent section coordinates and the hollow frustum's volume
168 (polygon without a hole: 224), scaled by model units cubed, distinguish the
complete physical path from a clamped or quantized partial sweep.

The existing permanent packaged helper adds 972 frustum cells across those
charts, three contact modes, three model scales, two placements, both profile
families and direct/legacy/V2 routes. Another 81 cells preserve shrinking,
aligned piecewise-linear and clamped normalized-law behavior. The 27 guide
cells check physical endpoint orientation only; no continuous guided-wall or
volume error certificate is asserted. Twelve refusal controls retain solid
bytes, original path data, history, exact checkpoint ownership and slot metrics,
including mismatch, unresolvable general-domain stations and existing parser
limits/invalid laws. Both canonical fresh and installed-tarball consumer drivers
invoke this helper; their immutable-source run and artifact hashes are recorded
in the PR qualification receipt rather than inferred from native binding tests.


Corner-mode follow-up: native knot multiplicity and endpoints are parameter
identities, not model-distance comparisons. At multiplicity degree, exact
one-sided endpoint tangent directions come from adjacent control-point
differences; positive rational weights change their magnitude, not direction.
Stationary or overmultiple joins retain close interior probes only when the
chart resolves them relative to both adjacent spans. An unresolvable direction
is unsupported, never evidence that there is no kink and never permission to
substitute Smooth for Miter/Round. Dispatch, miter bisectors and round setup use
the same side directions. Rounded tangent stations must meet their physical
setback within the existing linear tolerance; otherwise they are unsupported.
Miter splits below the existing math splitter's resolution are also typed
unsupported. Geometry tolerances and the math splitter remain unchanged.
