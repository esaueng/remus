# Face-splitter special-case ratchet (Open Kernel O2.3d), read by
# `scripts/check-splitter-ratchet.py`; that script documents each metric.
#
# Floors: `<floor> <metric>`, `LC_ALL=C sort`ed by metric. The allowed count of
# a metric is its floor plus its ledger raises below, and the observed count
# must equal it exactly.
#
# - A count may rise only with a ledger line naming the roadmap row that owns
#   the growth. Never raise a floor by hand.
# - When a count shrinks, set its floor to the observed count and delete that
#   metric's ledger lines in the same change, so the reduction is banked.
#
